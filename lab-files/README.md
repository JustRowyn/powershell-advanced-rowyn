#LM2:Testing, Debugging, and Source Control

Project purpose:
This project demonstrates debugging techniques (Write-Verbose, Write-Debug), automated testing 
with Pester, and version control practices using Git/GitHub for a PowerShell script that creates 
an Azure resource group.

Files included:
create-resourcegroup.ps1 (LM1) - script that creates an Azure resource group, updated with Verbose/Debug output
lm2-lab.md - documentation of errors found, debugging output, and test results
create-resourcegroup.tests.ps1 - Pester test verifying the resource group is created correctly
lm1-resourcegroup.log - transcript log from running the script

Lessons learned:
Learned how to troubleshoot PowerShell errors, add debug/verbose logging for visibility, write 
and run automated Pester tests, and manage a project using Git version control.
